# About

I cook one big thing most Sundays and eat it through the week. This is where those go.

Nothing here needs equipment beyond a heavy pot with a lid. If a recipe calls for something else, it is because the dish genuinely does not work without it, and it says why.

Quantities are metric with cup equivalents where they help. Corrections are welcome — the improve-this-page link at the bottom of any recipe files an issue with the page already filled in.
