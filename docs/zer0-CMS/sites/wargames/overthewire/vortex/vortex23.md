### What this level teaches

Researching an unfamiliar concept yourself.

### Key ideas

- **The title is a clue.** Think about what properties mirrors have, and how that might apply to data or code.
- **Independent research.** The page tells you plainly that you will need to look things up.
- **Test hypotheses.** Try small experiments with the program once you have an idea.

### How to approach it

1. Examine the program's behaviour closely and list what the title could be hinting at.
2. Search for relevant techniques once you have a hypothesis.
3. Build and test a minimal proof.

### Why it matters

Security work constantly means learning unfamiliar systems quickly.
