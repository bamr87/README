# The Threshold Heap

The vault's paradox gate scores five axes at up to two points each and passes a candidate at seven. Seven is a heap. Run [[zer0-CMS/sites/irony-works/vault/paradoxes/the-heap|the-heap]] on the gate itself and the argument writes itself: a ten is a paradox; one point of a judgment-based rubric cannot separate a paradox from a puzzle, because no reviewer's estimate is that fine; so a nine is a paradox, and an eight, and a six, and by the tenth step the compost ledger is a second canon. The premises are ones every reader of the rubric accepts. The reasoning is ten applications of a rule the rubric's own language invites. The conclusion is false, and the ledger says so in its first row.

The paradox is [[zer0-CMS/sites/irony-works/vault/forms/falsidical|falsidical]] and its fault is known, which is what makes it the only sorites in the vault with `standing: resolved`. The tolerance premise — one point does not matter — is false for the gate, not because the world contains a sharp boundary between paradox and puzzle but because someone wrote one into a configuration file. Williamson's epistemicism holds that vague predicates have exact boundaries we can never know; the vault's position is the same, minus the modesty. It knows where its boundary is. It chose seven, it could have chosen six, and it files this entry as the receipt: every threshold the vault enforces is a heap resolved by fiat, and the fiat is the [[zer0-CMS/sites/irony-works/vault/mirrors/the-borges-condition|price of having a canon at all]]. The [[zer0-CMS/sites/irony-works/vault/mirrors/alanis-gate|other gate]] runs on the identical stipulation and has never been asked about it.
