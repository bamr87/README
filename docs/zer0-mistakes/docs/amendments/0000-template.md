# NNNN — Title of the amendment

- **Status:** proposed
- **Date:** YYYY-MM-DD
- **Proposed by:** who (human or agent)
- **Ratified by:** the merged PR URL (leave blank until merged)
- **Affects:** constitution §N; PRD FRn/NFRn; feature ids (or `none`)
- **Supersedes:** none
- **Related:** ADRs, issues, specs

## Context

What problem or new fact makes the current rule wrong or incomplete.

## Amendment

The exact change to the constitution (quote the new text).

## Consequences

What changes for humans and agents; follow-up edits to PRD, feature catalog or AGENTS.md.
