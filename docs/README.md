# README documentation

> Every document of this repository's own, one line each — the rest of `docs/` is the generated fleet corpus.

`docs/` is the aggregated MkDocs corpus, so this repository keeps its own operator docs at the root (see the Standard deviations in [`AGENTS.md`](../AGENTS.md)). The fleet-wide review of every repository's documents is [`context/reports/docs_review.md`](../context/reports/docs_review.md).

**Backlog of record:** GitHub Issues with the fleet labels, unless `.github/sdlc.yml` declares a file backlog.
