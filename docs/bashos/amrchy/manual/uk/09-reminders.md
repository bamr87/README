# Нагадування

В Omarchy є вбудований спосіб створювати прості нагадування на основі таймера зворотного відліку з повідомленням. Ви можете зробити це через `Super + Ctrl + R`, переглянути всі встановлені через `Super + Ctrl + Alt + R` і очистити всі через `Super + Ctrl + Shift + R`. Усе також доступно через _Дії > Нагадування_. Можна також скористатися CLI командою `omarchy reminder 7 'Tea ready'`.
