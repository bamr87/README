# リマインダー

Omarchy には、カウントダウンタイマーとメッセージに基づくシンプルなリマインダーを設定する組み込みの方法があります。`Super + Ctrl + R` で設定し、`Super + Ctrl + Alt + R` で設定されたすべてのものを確認し、`Super + Ctrl + Shift + R` ですべてをクリアできます。すべて _実行 > リマインダー_ からもアクセスできます。CLI を `omarchy reminder 7 'Tea ready'` のように使うこともできます。
