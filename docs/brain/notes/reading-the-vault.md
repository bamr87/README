# Reading the vault

The vault has three layers, and each one answers a different question.

The corpus (`docs/<repository>/`) holds what each repository says about itself. It is collected, never edited here, and each page links back to its source.

The brain ([[brain/index|Second Brain]]) holds what the engine works out across repositories. Start at the [[brain/hot|hot cache]]. [[brain/tags|Tags]] that enough pages share become concept notes, and those notes are what connect repositories that never link to each other.

Notes (`notes/`) hold what people and agents decide is worth keeping. They are the only part written by hand.

When a link looks wrong, fix it where the page comes from. [[brain/health|Vault health]] lists what is broken and which repository owns it.
